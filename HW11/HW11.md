# ETCD
Действия выполняю на ВМ `PostgreSQL1`, `PostgreSQL2`, `PostgreSQL3` из под `root`.

Устанавливаю Etcd:
```bash
apt install etcd-server etcd-client -y
```

Конфигурационный файл (пример для `PostgreSQL1`):
```
ETCD_NAME="postgresql11"
ETCD_LISTEN_CLIENT_URLS="http://192.168.56.104:2379,http://127.0.0.1:2379"
ETCD_ADVERTISE_CLIENT_URLS="http://192.168.56.104:2379"
ETCD_LISTEN_PEER_URLS="http://192.168.56.104:2380"
ETCD_ELECTION_TIMEOUT="10000"
ETCD_HEARTBEAT_INTERVAL="2000"
ETCD_INITIAL_ADVERTISE_PEER_URLS="http://192.168.56.104:2380"
ETCD_INITIAL_CLUSTER_TOKEN="etcd"
ETCD_INITIAL_CLUSTER="postgresql1=http://192.168.56.104:2380,postgresql2=http://192.168.56.108:2380,postgresql3=
http://192.168.56.109:2380"
ETCD_INITIAL_CLUSTER_STATE="new"
```

Запускаю Etcd:
```bash
systemctl enable etcd --now
```

Проверяю состояние кластера:
```
etcdctl endpoint health --cluster
```

# PostgreSQL
Действия выполняю на ВМ `PostgreSQL1`, `PostgreSQL2` из под `root`.

Добавляю репозиторий PostgreSQL:
```bash
sh -c 'echo "deb http://apt.postgresql.org/pub/repos/apt $(lsb_release -cs)-pgdg main" > /etc/apt/sources.list.d/pgdg.list'
```

Добавляю ключ репозитория:
```bash
wget --quiet -O - https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo tee /etc/apt/trusted.gpg.d/postgresql.asc
```

Обновляю список пакетов:
```bash
apt update
```

Устанавливаю СУБД PostgreSQL 18:
```bash
apt install postgresql-18
```

Останавливаю PostgreSQL 18:
```bash
systemctl stop postgresql@18-main.service
```

Отключаю сервис PostgreSQL 18 из автозапуска:
```bash
systemctl disable postgresql@18-main.service
```

Удаляю содержимое директории данных:
```bash
rm -rf /var/lib/postgresql/18/main/*
```
# Patroni
Действия выполняю на ВМ `PostgreSQL1`, `PostgreSQL2` из под `root`.

Устанавливаю Patroni:
```bash
apt install patroni python3-etcd -y
```

Конфигурационный файл (пример для `PostgreSQL1`):
```
scope: "postgresql"
namespace: "/postgresql/"
name: postgresql1

etcd3:
  hosts: 192.168.56.104:2379,192.168.56.108:2379,192.168.56.109:2379

restapi:
  listen: 192.168.56.104:8008
  connect_address: 192.168.56.104:8008

bootstrap:
  method: initdb
  initdb:
  - encoding: UTF8
  - data-checksums

  dcs:
    ttl: 30
    loop_wait: 10
    retry_timeout: 10
    maximum_lag_on_failover: 1048576
    check_timeline: true
    postgresql:
      use_pg_rewind: true
      remove_data_directory_on_rewind_failure: true
      remove_data_directory_on_diverged_timelines: true
      use_slots: true
      parameters:
        wal_level: hot_standby
        hot_standby: "on"
        wal_keep_segments: 8
        max_wal_senders: 10
        max_replication_slots: 10
        max_worker_processes: 8
        wal_log_hints: "on"
        track_commit_timestamp: "off"
        password_encryption: "scram-sha-256"
      pg_hba:
      - local   all             all                                     peer
      - host    all             all             0.0.0.0/0               scram-sha-256
      - local   replication     all                                     peer
      - host    replication     all             0.0.0.0/0               scram-sha-256

postgresql:
  create_replica_method:
    - basebackup

  listen: "*:5432"
  connect_address: 192.168.56.104:5432
  use_unix_socket: true
  data_dir: /var/lib/postgresql/18/main/
  bin_dir: /usr/lib/postgresql/18/bin
  config_dir: /etc/postgresql/18/main
  pgpass: /var/lib/postgresql/18-main.pgpass
  authentication:
    replication:
      username: "replicator"
      password: "1234"
    superuser:
      username: "postgres"
      password: "1234"
    rewind:
      username: "rewind"
      password: "1234"

  parameters:
    unix_socket_directories: '/var/run/postgresql/'
    logging_collector: 'on'
    log_directory: '/var/log/postgresql'
    log_filename: 'postgresql-18-main.log'
```

Проверяю конфигурацию:
```bash
patroni --validate-config /etc/patroni/config.yml
```

Запускаю patroni:
```bash
systemctl enable patroni --now
```

Проверяю кластер patroni:
```bash
patronictl -c /etc/patroni/config.yml topology
```

![](../project/Pasted%20image%2020261013203239.png)

В случае ошибок при инициализации кластера:
```bash
sudo systemctl stop patroni
sudo rm -rf /var/lib/postgresql/18/main
sudo mkdir /var/lib/postgresql/18/main
sudo chmod 700 /var/lib/postgresql/18/main
sudo chown postgres:postgres /var/lib/postgresql/18/main

# На любой машине с ETCD
etcdctl del /postgresql/ --prefix
```

# Haproxy
Действия выполняю на ВМ `PostgreSQL3` из под `root`.

Устанавливаю Haproxy:
```
apt install haproxy -y
```

Конфигурационный файл:
```
global
        log /dev/log    local0
        chroot /var/lib/haproxy
        stats socket /run/haproxy/admin.sock mode 660 level admin
        stats timeout 30s
        user haproxy
        group haproxy
        daemon

defaults
        log     global
        mode    tcp
        option  tcplog
        option  dontlognull
        timeout connect 5000
        timeout client  50000
        timeout server  50000

frontend postgres_read_write
        bind *:5432
        default_backend master_nodes

backend master_nodes
        mode tcp
        option httpchk GET /master
        http-check expect status 200
        default-server inter 3s fall 3 rise 2 on-marked-down shutdown-sessions
        server postgresql1 192.168.56.104:5432 check port 8008
        server postgresql2 192.168.56.108:5432 check port 8008
```

Запускаю Haproxy:
```
systemctl enable haproxy --now
```

Устанавливаю клиент postgresql:
```
apt install postgresql-client -y
```

Проверяю подключение через haproxy:
```
psql -d postgres -U postgres -h 192.168.56.109 -p 5432
```
