## Настройка доступа к PostgreSQL

По заявлению ИИ помощника SberCloud не поддерживает назначение публичного адреса на ВМ для Managed PostgreSQL.
![](../project/Pasted%20image%2020260723112923.png)

Успешно устанавливаю Nginx
Настраиваю сетевой фильтр:
```bash
sudo ufw allow OpenSSH
sudo ufw allow 55432
sudo ufw enable
```

Создаю каталог для конфигурации Nginx:
```bash
sudo mkdir -p /etc/nginx/streams
```

Создаю файл конфигурации:
```bash
sudo nano /etc/nginx/streams/postgres-proxy.conf
```
```
server {
    listen 55432;
    proxy_pass 10.0.0.161:5432;
    proxy_connect_timeout 5s;
    proxy_timeout 600s;
}
```

Добавляю настройки в Nginx.conf в блок перед http:
```bash
sudo nano /etc/nginx/nginx.conf
```
```
stream {
    log_format basic '$remote_addr:$remote_port -> $server_addr:$server_port '
                     'upstream: $upstream_addr status: $status';
    access_log /var/log/nginx/postgres-proxy-access.log basic;
    error_log /var/log/nginx/postgres-proxy-error.log;
    include /etc/nginx/streams/*.conf;
}
```

Применяю конфигурацию:
```bash
sudo nginx -t
sudo systemctl restart nginx
```

Проверяю слушает ли Nginx нужный порт:
```bash
sudo ss -tulpn | grep 55432
```
```
tcp   LISTEN 0      511            0.0.0.0:55432      0.0.0.0:*    users:(("nginx",pid=35096,fd=7),("nginx",pid=35095,fd=7))
```

## Выводы по SberCLoud

1. Нельзя настроить сетевые группы безопасности для PostgreSQL Managed
2. Нельзя настроить публичный ip для PostgreSQL Managed
3. Симпатичный и удобный интерфейс
4. Возможность настройки `Бизнес` и тестового окружения
5. Высокая стоимость по сравнению с VK Cloud
6. Удобный ИИ помощник, но недостаточно умный). Выполняет реальные действия с ресурсами без подтверждения со стороны пользователя
7. Актуальная версия PostgreSQL
