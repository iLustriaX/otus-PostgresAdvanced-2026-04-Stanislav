# Установка PostgreSQL

Обновляю пакеты:
```bash
sudo apt update && sudo apt upgrade -y -q
```

Добавляю репозиторий PostgreSQL:
```bash
sudo sh -c 'echo "deb http://apt.postgresql.org/pub/repos/apt $(lsb_release -cs)-pgdg main" > /etc/apt/sources.list.d/pgdg.list'
```

`lsb_release -cs` выводит кодовое имя дистрибутива. Например для Ubuntu 22.04:
```bash
user@otus-hw06:~$ lsb_release -cs
No LSB modules are available.
noble 
```

Добавляю ключ репозитория:
```bash
wget --quiet -O - https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo tee /etc/apt/trusted.gpg.d/postgresql.asc
```

Обновляю список пакетов:
```bash
sudo apt update
```

Устанавливаю СУБД PostgreSQL 18:
```bash
sudo apt install postgresql-18
```

Скачиваю демо-базу компании Postgres Pro: https://postgrespro.ru/education/demodb

Переношу файл на ВМ в облаке:
```
scp C:\Users\Zotac\Downloads\demo-20250901-6m.sql.gz user@158.160.128.117:/home/user
```

Распаковываю и создаю демо-базу:
```bash
gunzip -c demo-20250901-6m.sql.gz | sudo -u postgres psql
```

# Проверка базовой производительности

Подключаюсь к СУБД PostgreSQL:
```bash
sudo -u postgres psql
```

Создаю БД для pgbench:
```SQL
CREATE DATABASE pgbench_db;
```

Инициализирую тестовые таблицы через pgbench:
```bash
sudo -u postgres pgbench -i -s 100 pgbench_db
```

Размер получившейся БД:
```bash
sudo -u postgres psql -c "SELECT pg_size_pretty(pg_database_size('pgbench_db'));"
```
```
 pg_size_pretty
----------------
 1503 MB
(1 row)
```

Запускаю бенчмарк:
```bash
sudo -u postgres pgbench -c 1 -j 2 -T 60 pgbench_db
```

`-c` - количество клиентов. Буду постепенно увеличивать пока не найду "потолок".
`-j` - количество потоков. На ВМ используется 2-ух ядерный процессор, поэтому устанавливаю значение 2.
`-T` - время теста в секундах. Рекомендуемое минимальное значение - 60, для исключения случайных факторов.

# Оптимизация СУБД

Ресурсы системы:
	`CPU`: 2 ядра
	`RAM`: 2ГБ
	`Диск`: 20ГБ HDD

Настройки конфигурации СУБД возьмём с https://tantorlabs.ru/pgconfigurator
## noatime

`noatime` — это опция монтирования файловой системы в Linux. Она **отключает обновление времени последнего доступа (atime)** при чтении файла.

Определяем на каком диске лежат файлы СУБД:
```bash
df -h /var/lib/postgresql
```
```
Filesystem      Size  Used Avail Use% Mounted on
/dev/vda1        19G  5.4G   14G  29% /
```

Сейчас в `fstab`:
```
LABEL=cloudimg-rootfs   /        ext4   discard,commit=30,errors=remount-ro     0 1
LABEL=UEFI /boot/efi vfat umask=0077 0 1
```
Корректируем первую запись, т.к. именно на этом диске лежит PostgreSQL:
```bash
sudo nano /etc/fstab
```
```
LABEL=cloudimg-rootfs   /        ext4   discard,commit=30,errors=remount-ro,noatime     0 1
LABEL=UEFI /boot/efi vfat umask=0077 0 1
```

Перезагружаем конфигурацию fstab:
```bash
sudo systemctl daemon-reload
sudo mount -o remount /
```
