# Установка PostgreSQL

Действия выполняю на ВМ `Postgresql` из под `root`.

Добавляю репозиторий PostgreSQL:
```bash
sh -c 'echo "deb http://apt.postgresql.org/pub/repos/apt $(lsb_release -cs)-pgdg main" > /etc/apt/sources.list.d/pgdg.list'
```

Добавляю ключ репозитория:
```bash
wget --quiet -O - https://www.postgresql.org/media/keys/ACCC4CF8.asc | sudo tee /etc/apt/trusted.gpg.d/postgresql.asc
```

Обновляю список пакетов:
```bash
apt update
```

Устанавливаю СУБД PostgreSQL 18:
```bash
apt install postgresql-18
```

```
systemctl status postgresql@18-main
```

# Генерация и загрузка данных

Цель тестирования — сравнить производительность PostgreSQL и CockroachDB под одинаковой OLTP-нагрузкой при сопоставимом объёме данных (~10 ГБ). Обе системы тестируются с одинаковыми параметрами: 10 одновременных клиентов, 5 минут работы, 30 секунд прогрева. Это позволяет оценить, как каждая СУБД справляется с типичной транзакционной нагрузкой и как ведёт себя при росте конкуренции.

В качестве нагрузки выбран бенчмарк **TPC-B («банки»)** — имитация переводов между счетами. Он встроен в `pgbench` как нагрузка по умолчанию, а для CockroachDB существует прямой аналог `bank workload` с той же логикой транзакций.


На ВМ `postgresql`:
```
sudo -u postgres psql
```
```
ALTER USER postgres WITH PASSWORD 'postgres';
```
```
pgbench -i -s 625 -U postgres -d postgres -h 127.0.0.1
```

![](../project/Pasted%20image%2020261015201146.png)

На ВМ `cockroachdb`:
```
cockroach workload init bank \
  'postgresql://root@localhost:26257/bank?sslmode=disable' \
  --rows=75700000
```

```
cockroach sql --insecure --host=localhost:26257
```
```
SET allow_unsafe_internals = true;

WITH range_stats AS (
    SELECT crdb_internal.range_stats(start_key) AS stats
    FROM crdb_internal.ranges_no_leases
)
SELECT pg_size_pretty(
    sum((stats->>'key_bytes')::INT + (stats->>'val_bytes')::INT)
) AS logical_size
FROM range_stats;
```

# Выводы

| Метрика                    | PostgreSQL | CockroachDB   | Разница            |
| -------------------------- | ---------- | ------------- | ------------------ |
| Выполнено операций         | 207 280    | 332 637       | +60% (CockroachDB) |
| Пропускная способность     | 691 TPS    | 1 109 ops/sec | +60% (CockroachDB) |
| Средняя задержка           | 14.47 мс   | 9.0 мс        | −38% (CockroachDB) |
На одноузловом кластере при 10 одновременных клиентах и сопоставимом объёме данных (~10 ГБ) **CockroachDB показала пропускную способность на 60% выше и среднюю задержку на 38% ниже, чем PostgreSQL**.

Важно заметить, что обе СУБД используются с параметрами по умолчанию
